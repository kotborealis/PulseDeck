## F-Droid

PulseDeck is prepared for submission to the official F-Droid repository. The source repository includes the required open-source license, Gradle Wrapper, release tag, and Fastlane-compatible app metadata. F-Droid can build and sign the APK independently; no private Android signing key is stored in this repository.

The app is submitted through the [F-Droid inclusion process](https://f-droid.org/en/docs/Submitting_to_F-Droid_Quick_Start_Guide/).
